
## 3. 明早验收清单（按优先级）

> 判据都写成"看到什么算通过"。任何一条不通过，记下现象即可，不用改代码。

### P0 —— 主链路（5 分钟）

1. **冷启动 → 权限**
   - 期望：打开直接是取景器（没有首页），系统弹相机权限；允许后 1–3 秒出真实画面。
   - 拒绝一次：取景器显示「需要相机权限 / 在系统设置中允许使用相机」，**并且有一个「去设置」按钮**。
2. **拍一张**
   - 期望：按快门 → 闪白 → 成片页「正在冲洗」→ 约 3–5 秒出图（非 debuggable 包）；成片正立。
   - **新变化**：成片页参数网格（EXPOSURE / 焦距等）应从「—」变成**真实值**（如 `1/125 · f/1.8`、`ISO xxx`、`xx mm`）。相机没给某项时该项仍是「—」，这是正确行为。
3. **系统相册**
   - 期望：照片出现在 `Pictures/Pocket CCD/`；点开系统相册「详情」应能看到 **焦距 / 光圈 / 快门 / ISO**（新变化）；照片**不能**是旋转 90° 的。
4. **胶片相册（新）**
   - 取景页左下「相册」→ 点任意格子：应打开全屏查看器（卷名 / `序号 / 总数` / 时间 / 收藏 / 关闭）。
   - 左右滑动：**第一张向左能滑到最后一张，最后一张向右能回到第一张**（首尾循环）。
   - 点「收藏」：变成「已收藏」；**杀进程重开 App**，收藏仍应在；顶部筛选「★ 收藏」只剩收藏的照片。
   - 顶部筛选 chip：全部 / ★收藏 / 每个真实卷名；切换后分组仍正确，空组隐藏。
5. **闪光灯重绑（修过的 bug）**
   - 开闪光灯 → 进「相册」→ 返回取景页 → 再拍一张：**闪光灯应仍然真的闪**，图标也仍是开态。
6. **权限自救（修过的 bug）**
   - 系统设置里关掉相机权限 → 回 App：取景器应变成权限空态；点「去设置」→ 打开权限 → 返回：**应自动恢复取景**，不用杀进程。
7. **相机被占用后的自愈**
   - 打开别的相机 App 占着摄像头 → 切回 Pocket CCD：可能先显示错误/重连，等 1–3 秒应自己恢复；若仍不行，切到胶卷库再回来应恢复。

### P1 —— 这一轮新增/改变的（5 分钟）

8. **桌面图标（新）**：应是一个**近黑底 + 香槟金镜环**的图标，不再是安卓默认机器人。
9. **变焦档位（变了）**：应只有 `1×` 和长焦档（如一加 13 的 `3.2×`）；**不应再出现 0.6×**（D-054：0.6× 按下去没反应，且会破坏 pack 的物理尺度，所以本轮直接隐藏）。点 `3.2×` 画面应真的变焦，Toast 显示实际倍率。
10. **EV 补偿**：右侧 `±` 键点开 → 向左展开刻度尺；拖动指针，读数窗显示 `+0.3` 之类；拍出来的照片亮度应真的有变化。
11. **TalkBack（可选）**：打开 TalkBack，桌面/Settings → 取景页，图标按钮应能读出「快门」「闪光灯已开/已关」「变焦 2×」等，而不是"按钮"。
12. **照片墙滚动**：快速上下滚，不应明显掉帧/卡死；点开大图不应黑屏太久（先显示「正在读取底片…」）。

### P2 —— 已知还没做/没验的（不用现在验）

- **成片页/照片墙的真机截图**：T9-018..020 一直没有真机图，这轮无设备仍然补不了。
- **冷启动 / 从相册返回会绑两次相机（P1-10，未修）**：第一次 `targetSize=null`，拿到真实尺寸后
  会按 programmedSize 再绑一次，取景器会多黑一下。修它需要在真机上验证时序（还要避免在 50MP
  机型上选到最大分辨率），无设备时动绑定逻辑风险大于收益，故留到有设备时做。
- **`stripRows` 调优（P1-9，未做）**：内核 halo 重叠约 1.94×，理论上把 stripRows 从 128 提到
  256–384 可省 25–30% 内核时间；但 Halide 对 tile 高度有向量化偏好，必须真机逐档测。
- **`nativeAbiVersion` 未校验（P2-7）**：换 `.so` 不会在构建期报错；属"以后换内核时"的风险。
- 真机性能、47 卷全量、Rec.2020 色彩口径、App 内删除照片、旋转屏、多机型。
- 详细清单见 `README.md` 的「当前状态」与 `TASK_BOARD.md` 的 T9-031。

## 10. 按钮系统与按压反馈（v0.3.1，D-060）

你的原话：「没有设计也没有交互，完全没有细节；还有哪些按钮，你都能好好设计一下吗，
还有按下后的反馈，以及按钮的布局。」这一节逐条回答。

### 10.1 全 App 按钮清单（33 个实例 / 20 类）

完整表见 [`docs/design/interaction-system.md`](design/interaction-system.md)。四类层级：

- **主操作**：快门（88dp 凹槽 / 72dp 环）——唯一会闪白+冲洗的动作；
- **图标操作**：返回、闪光灯、九宫格、相册、设置（48dp 热区 / 40dp 圆 / 18dp 图标）；
- **文字操作**：重拍/继续拍摄/去设置/重新扫描（48dp 高，主/次/幽灵三语气）；
- **可选项**：筛选 chip、变焦/EV 档位轨、底盖副键（热区≥48dp，视觉更小）。

### 10.2 按下反馈：统一三件事

1. **视觉**：按下缩到 0.96（快门 0.94 + 下压 1dp），叠一层 5% 白/黑覆盖；
2. **触觉**：按下瞬间 `KEYBOARD_TAP` 轻震（禁用态不震）；
3. **时序**：90ms spring 到位、松手回弹；开/关与选中用 160ms 颜色过渡。

**不使用 Material ripple**：近黑底上几乎不可见，且是"App 组件"语言；相机需要机械键的
"先缩再回弹"。列表行例外：只叠 4–6% 覆盖、不缩放、不震动（高频列表震一屏会成噪音）。

### 10.3 布局

页头统一 56dp/左右 20dp；内容边距 24dp；间距阶梯 4/8/12/16/24/32；底盖两个副键中心
距中线约 110dp、与快门之间留 42dp 误触安全带；并排文字按钮等宽、gap 12、主操作在右。
热区红线：全部 ≥48dp，相邻 ≥8dp。详见规范图
[`docs/design/control-sheet-v2.png`](design/control-sheet-v2.png)。

### 10.4 已知的交互债（没在这一版解决）

1. **换卷**紧邻快门且无确认，误触会把本卷计数归零——计划改长按 600ms + 触觉警告，或搬进胶卷库。
2. **EV 刻度条 22dp 热区**：视觉加高会顶取景器，目前用可调节语义兜底。
3. 旋转屏会关闭查看器、重置筛选。

### 10.5 证据

`assembleBenchmark` + 61/61 单测绿；真机未验。下面四项需要你看：
① 快门按下 1dp 行程+金环变亮是否"像机械键"；② 顶栏图标按下 5% 覆盖是否可感知；
③ 文字按钮主/次对比是否够；④ 底盖两个副键的位置是否顺手、会不会误触快门。
