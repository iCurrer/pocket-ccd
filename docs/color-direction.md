# Pocket CCD — 配色与材质方向研究（V2）

**日期：** 2026-10-17  
**状态：** V2 已落地，数值 `PROVISIONAL`
**触发反馈：** “UI 做的太像网页了，一点都不像玩具相机和 app 的质感。”

---

## 1. 为什么 V1 失败

V1 是“燕麦纸面 + 灰绿 + 细字列表”：

- 颜色本身不刺眼，但**结构**还是网页：整页背景、文本链接、分隔线、设置列表；
- 灰绿 + 米白很容易落到“家居/文具/网页”的语感，而不是塑料玩具；
- 单色机身 + 大量小字，缺少实体相机的厚度、按钮和屏幕；
- 所以即使配色变暖，仍然像“套了玩具色板的网页”。

**结论：** 只换颜色不够，必须换**材质和结构**。V2 的目标是让每个页面像一台实体玩具相机的一部分。

## 2. 玩具相机的视觉线索

参考 2000 年代消费级玩具数码相机 / 彩色塑料相机：

| 线索 | V2 做法 |
|---|---|
| 彩色塑料外壳 | 黄油黄机身 `#F2C14E` / `#DFA92F` |
| 奶油色内面板 | 奶油面板 `#FFF4E2` / `#F3DFC2` |
| 薄荷绿功能键 | `#9FD8C4` / `#6FB7A4` |
| 珊瑚红快门 | `#E76F51` / `#C8553D` |
| 深青 LCD/取景窗 | `#173B3A` / `#0C2423` |
| 厚塑料边缘 | 18dp 阴影 + 2dp 高光边 + 机身圆角 36dp |
| 实体按钮 | 圆形凸起、6dp 阴影、白高光边 |
| 机刻字 | 加粗圆润无衬线 + 字距，不用等宽字体 |
| 小屏幕/取景窗 | 深青内嵌屏 + 3dp 深色边框 |

暖中性色趋势仍然有效（低饱和、暖白、深色屏幕），但不再把页面做成“奶油色网页”，而是做成**有厚度的塑料相机**。

## 3. 备选方案

| 方案 | 机身 | 面板 | 按钮/快门 | 评价 |
|---|---|---|---|---|
| A（采用） | 黄油黄 | 奶油 | 薄荷 + 珊瑚 | 最像玩具相机；暖、活泼、仍有高级感 |
| B | 奶油白 | 浅灰 | 薄荷 + 珊瑚 | 更干净，但塑料玩具感弱 |
| C | 珊瑚红 | 奶油 | 薄荷 + 黄油 | 更抢眼，但大面积红色容易累 |

选择 A：机身颜色负责“玩具”，奶油面板负责“干净”，珊瑚只出现在快门和少量强调。

## 6. 结构后果

- 首页不再是“奶油网页 + 品牌字 + 文本链接”，而是一台黄油玩具相机：
  - 大镜头、闪光灯窗、珊瑚快门、`FILM` 薄荷键、设置小圆键；
  - 没有底部 `GALLERY / OPEN CAMERA` 文本行。
- 拍摄页是一个机身背板：
  - 深青取景窗 + 厚塑料边框；
  - 薄荷闪光灯键、珊瑚快门、黄油前后摄键；
  - 顶栏只保留一个小圆返回键 + 品牌。
- 照片墙是机身里的“胶片仓”：
  - 深青屏幕 + 奶油照片纸；
  - 2 列实体照片格，不是网页卡片网格。
- 成片页是相机吐出的照片：
  - 奶油相纸 + 轻微旋转 + 阴影；
  - 底部两个物理圆键，而不是文本按钮。
- 设置页是机身 LCD：
  - 深青屏幕 + 薄荷/珊瑚选择键；
  - 过滤/版本/隐私在屏内，不再是整页网页列表。

## 7. 风险

- 玩具色很容易做“廉价”，必须靠低饱和、厚阴影、细高光和克制的颜色数量压住；
- 黄油黄大面积可能偏亮，需要真机看；
- 深青屏幕 + 奶油面板的强对比需要确认户外可读性；
- 颜色来自设计推断与产品语义，不是对某台真实相机的取样；
- 若真机显得太童趣，可降低黄油饱和度，而不是退回网页布局。
