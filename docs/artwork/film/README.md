# 胶卷片盒美术（8 支）

拍摄页胶卷卡里那一格的成品图。透明底 PNG，2:3 竖构图，供 `CameraConsole.kt` 的
`FilmArtwork(painter = …)` 直接替换占位暗盒。

## 结构（8 支完全一致，只有纸标颜色与文字不同）

自顶向下：黑色哑光塑料顶盖（含一处凸起的卷轴座）→ 细黄铜带 → 纸标 → 细黄铜带 → 黑色底圈。

这个结构是从一张参考图反推的（黑色端盖 + 上下两道黄铜带 + 金色大字），比原来的
"拉丝铝 + 抽象色块" 更像真胶卷，也正好落在 App 的暖白 + 黄铜色系里。

每目录内 `<stock>.png` 是成品（已抠透明底）；同目录另一张 `Edit_*.png` 是模型原图，
**背景里的棋盘格是画进像素里的、没有 alpha**，留着是为了能重新抠。

## 重做流程

1. 以 `portra400/Edit_the_construction…png` 为底图，只改"纸标底色 + 两行字"重新生成
2. `python tools/cutout.py <原图> <成图> --thresh 110`

`--thresh` 默认 80 只够跨过 71 的棋盘格色差；若某次生成的棋盘对比更强（比如 232 vs 255，
三通道差之和 83），必须给 110，否则深色格会残留。

## 商标说明

标签上的名字来自真实胶卷品牌。内测分发无妨；**要上架或写软著材料时需换成自创名**
（`PORTRA` → `PC400` 之类），改法只是重跑上面的流程换两行字。
