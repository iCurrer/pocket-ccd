# 交互语法 v1：按钮系统、按下反馈与布局网格

**日期：** 2026-10-23 ｜ **对应版本：** v0.3.1 ｜ **决策：** D-060 ｜ **实现：** `ui/film/FilmControls.kt`

> 这份文档回答三件事：**有哪些按钮、每个按钮该长什么样、按下去发生什么。**
> 原则只有一句：一屏里的可点东西必须能按**层级**归类，每类只有一种尺寸/状态/反馈，
> 不允许临时发明。控件规范图：`docs/design/control-sheet-v2.png`

---

## 1. 四类控件（层级）

| 层级 | 用在哪 | 尺寸 | 视觉 | 按下反馈 |
|---|---|---|---|---|
| **主操作** | 快门 | 88dp 凹槽 / 72dp 环 | 唯一暖白+金环+红点 | 缩放 0.94 + 下压 1dp + 金环 30→62% + 面暗 6% + 轻震 |
| **图标操作** | 返回、闪光灯、九宫格、相册、设置 | 48dp 热区 / 40dp 圆 / 18dp 图标 | 无底幽灵；active = 金 14% 底 + 金图标 | 缩放 0.96 + 白 5% 覆盖 + 轻震 |
| **文字操作** | 重拍/继续拍摄/去设置/重新扫描 | 48dp 高（幽灵 40dp） | 主=浅色实底，次=玻璃+1px 边，幽灵=无底 | 缩放 0.96 + 覆盖 6% + 轻震 |
| **可选项** | 筛选 chip、变焦/EV 档位、面板副键 | 热区 48（档位 40×64、副键 64×48） | 32dp 胶囊 / 纯文字轨 / 幽灵键 | 0.96–0.97 缩放 + 覆盖 5% + 轻震 |

**唯一的例外是列表行**（设置行、胶卷卡、相册格）：只叠 4–6% 覆盖、不缩放、不震动——
高频滚动列表里每一格都震会变成噪音；相册格保留 0.97 缩放给"按到照片"的物理感。

## 3. 按下反馈（三件事，缺一件算没做完）

```
按下瞬间   → 缩放 0.96（快门 0.94 + 下压 1dp）
           → 覆盖层：深色面白 5%、浅色金属面黑 5%
           → 触觉：KEYBOARD_TAP 轻震（禁用态不震）
90ms       → spring(0.62, 900) 到位
松开       → spring 回弹（不是线性 100ms）
状态切换   → 颜色 animateColorAsState 160ms（开/关、选中）
禁用       → 35–40% 透明，无缩放、无覆盖、无震动
```

**不用 Material ripple**：涟漪在近黑底上几乎不可见，且它是"App 组件"的语言；
这台相机的反馈应该像机械键——先缩、再回弹。列表行例外见第 1 节。

## 4. 布局网格

- **页面边距**：内容 20–24dp；页头统一 56dp 高、左右 20dp；标题居中，两侧各留 48dp 占位。
- **间距阶梯**：4 / 8 / 12 / 16 / 24 / 32；同组控件 8–12，组间 24。
- **底盖**：副键中心距中线 ≈110dp（左右各一），快门居中；三者底部基线对齐；
  副键与快门之间至少 32dp 误触安全带（当前 42dp）。
- **文字按钮**：两个并排时等宽、gap 12；主操作在右（拇指/阅读终点）；整行距手势条 ≥16dp。
- **热区红线**：所有可点控件 ≥48dp；相邻热区之间 ≥8dp；破坏性动作（换卷）不得紧邻主操作——**当前仍是债**。
- **对齐**：文本左对齐到内容边；数字右对齐；图标中心对齐到所在行的光学中心，而不是行高中心。

## 5. 已知的交互债（下一步）

1. **换卷紧邻快门且无确认**：误触一次本卷计数归零。计划：长按 600ms 触发 + 触觉警告，或搬进胶卷库。
2. **EV 刻度条 22dp 热区**：视觉不能加高（会顶取景器），目前用可调节语义兜底；真机看是否需要加"拖动条外扩 10dp 无效区"的折中。
3. **旋转屏**：查看器关闭、筛选重置（`remember` 非 `rememberSaveable`）。
4. **列表行不缩放**是有意的；但设置行的 4% 覆盖在真机低亮度下是否可见，需要真机确认。
