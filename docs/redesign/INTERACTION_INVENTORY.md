# Pocket CCD — 交互清单

**基线：** `3166831` / 0.8.8  
**目标：** 记录当前真实交互和状态，供视觉改版保持行为一致。本文不是新功能提案。

## 1. 全局导航与生命周期

### 1.1 导航状态机

| 当前状态 | 事件 | 结果 |
|---|---|---|
| 任意非 `CAMERA` | `OpenCamera` / Tab“拍摄” | `CAMERA` |
| 任意页面 | `OpenGallery` | `GALLERY` |
| 任意页面 | `OpenFilms` | `FILMS` |
| 任意页面 | `OpenDiscover` | `DISCOVER` |
| 任意页面 | `OpenSettings` | `SETTINGS` |
| `CAMERA` 或 `GALLERY` | `OpenDetail` | `DETAIL`，记录来源 |
| `DETAIL` | `NavigateBack` | 回到 `detailOrigin` |
| 非 `CAMERA` 平级页 | `NavigateBack` | 回到 `CAMERA` |
| `CAMERA` | `NavigateBack` | 状态不变，交给系统结束 Activity |

**视觉改版不得改变：**

- 相机是根；
- 底部 Tab 是平级切换；
- 详情是压栈页；
- TabBar 不显示于详情和查看器；
- 系统返回优先关闭查看器/许可页，再执行页面返回。

### 1.2 页面方向

- 进入 `CAMERA`：设置 `SCREEN_ORIENTATION_SENSOR_LANDSCAPE`。
- 进入任何其它目的地：设置 `SCREEN_ORIENTATION_PORTRAIT`。
- `configChanges` 阻止朝向变化重建 Activity。
- 每当配置方向变化且目的地为 `CAMERA`，`cameraNonce++` 强制重绑相机。

**风险：**

- 方向切换可能产生一次转向帧；
- 横屏布局只对真实 804×361dp 做 Robolectric 截图，尚无真机证据；
- 从相册打开详情时不应绑定相机，从快门打开详情时必须保持相机挂载。

### 1.3 生命周期与恢复

- 进入前台：执行相册对账、重查相机权限、启动会话探针。
- 会话探针最多等待 `3 × 250ms`，仍不可用才重绑。
- 相机绑定失败：最多退避重试两次，间隔 1.2s / 2.4s。
- 离开相机/快门详情：解绑相机并标记 `CameraState.Pending`。
- 取景/详情期间保持屏幕常亮。
- 相机重绑后重新应用闪光灯、变焦、EV。
- 九宫格使用 `rememberSaveable`；其它相机状态在 Activity 不重建的常规页面切换中保留。

**视觉改版不得改变：** 对账、权限重查、探针、重绑、解绑和 screen-on 策略。

### 1.4 快门

1. 检查 `handle` 存在且已附着；
2. 检查 `cameraUi.canShoot`；
3. 清空当前详情照片 id；
4. 触发全屏闪白；
5. `viewModel.capture(bound::takeJpeg, imprint)`，同步进入 `Capturing`；
6. 立即发送 `OpenDetail`；
7. 详情页显示真实阶段；
8. 完成后刷新照片列表与存储占用。

**特殊行为：**

- 连点由 `AtomicBoolean`、UI busy 状态和按钮 disabled 共同防重；
- 相机未附着而按快门会提示正在重连并触发重绑；
- 快门 5 秒拿不到回调时进入失败态并请求重绑；
- 详情失败页重试会再拍一张，不自动复用上一张文件。

## 2. `CAMERA` 交互

| 控件/手势 | 当前行为 | 可见状态 | 视觉改版边界 |
|---|---|---|---|
| 取景窗点按 | `startFocusAndMetering(AF + AE)` | 对焦中 / AF LOCK / AF FAIL，2.2s 后消失 | 可改对焦标记；必须使用真实回执 |
| 快门 | 真实拍照并进入详情 | 可用/禁用/闪白 | 可改视觉；不可改状态顺序 |
| 闪光灯 | `ImageCapture.flashMode` | 开/关/无闪光灯 | 可换取景器状态；不能假装开启 |
| 九宫格 | UI 三分线开关 | 开/关 | 可改线条；不能烧进成片 |
| 变焦档 | `CameraControl.setZoomRatio()` | 选中档；可用倍率来自镜头/CameraX | 可改控件；不可显示 <1× 无效档 |
| EV 入口 | 打开/关闭 EV 面板 | 中性/非零/不支持时不显示 | 可改仪表；不可虚构范围 |
| EV 减/加 | 调用 `requestExposure(index ± 1)` | 达上下限时禁用 | 每次只变真实 index 一档 |
| EV 归零 | `requestExposure(0 clamp)` | - | 保持语义 |
| 胶卷芯片 | `OpenFilms` | 当前卷名与现存张数 | 可改标签；不恢复 36 张概念 |
| 相册缩略图 | `OpenGallery` | 最近真实缩略图或占位 | 不展示假照片 |
| 设置图标 | `OpenSettings` | - | 保持入口 |
| dock 上滑 | 阈值 48dp，打开目的地抽屉 | 抽屉、遮罩、dock 淡出 | 手势方向/入口可重设计，但必须可从相机到所有五个目的地 |
| 抽屉四格 | 相册、胶卷、发现、设置 | 抽屉状态 | 不能新增假页面 |
| 点遮罩/返回 | 关闭抽屉 | - | 保持 |
| 权限空态 | 打开应用设置 | 无权限/相机未准备 | 不能只显示无操作文案 |
| 自动换卷提示 | 6 秒后清除 | 真实原因 | 不可静默换卷 |

### 2.1 当前交互/无障碍问题

- 多个相机顶栏按钮和变焦按钮显式使用 44dp `size`，低于项目声称的 48dp 最小热区。
- `GlassChip` 的高度约由 12sp 行高 + 18dp 垂直 padding 构成，常见约 34dp；筛选和胶卷芯片没有统一补 48dp 热区。
- 横屏没有上滑抽屉，也没有直达发现页的可见入口；只能先进入相册后通过 TabBar 去发现。
- 横屏代码的 `notice` 与 `blockReason` 未显示；只有贴花状态显示在右下。
- `AppRoot` 当前未传 `imprintLabel = imprint.label()`，截图中的贴花状态只存在于测试装配。

这些问题可在视觉改版中修正，不改变业务逻辑。

## 3. `GALLERY` 交互

| 控件/手势 | 当前行为 | 状态/数据 |
|---|---|---|
| 筛选 chip | 改写本地 `filter` | 全部 / 收藏 / 真实卷名 |
| 刷新 | `refreshRoll()` + `reconcileGallery()` | 列表刷新；无 loading 视觉 |
| 点缩略图 | `onOpenViewer(ViewerRequest(visible, index))` | 打开外层模态 |
| 空相册“去拍摄” | `OpenCamera` | 空态 |
| 收藏筛选空态“看全部” | 本地 filter 回全部 | 空态 |
| TabBar | 平级导航 | 当前页显示 |
| 返回 | 回相机 | - |

**视觉保留：**

- 筛选标签来自真实数据；
- 当前筛选为空时显示“还没有收藏”或对应空态；
- 网格滚动时由 TabBar overlay 覆盖，列表需要自身预留底部空间；
- 加载和失败占位不得伪装成真实照片。

## 4. 全屏查看器交互

| 控件/手势 | 当前行为 |
|---|---|
| 水平滑动 | 切换照片；1000 遍虚拟页 + 取模，首尾循环 |
| 关闭按钮 | `viewerRequest = null` |
| 系统返回 | `BackHandler` 关闭查看器，优先于外层页面返回 |
| 收藏 | 写入/移除 `FavoritesStore`；当前模态列表不重排 |
| 详情 | 关闭查看器并进入 `DETAIL` |
| 列表为空 | 通过 `LaunchedEffect` 自动关闭 |

**视觉保留：**

- 查看器覆盖 TabBar；
- 黑色灯箱和全图 `Fit` 语义可保留或重设计，但不能固定裁成 3:4；
- 顶部计数和底部照片身份信息必须来自真实条目。

## 5. `DETAIL` 交互

| 状态/动作 | 当前行为 |
|---|---|
| 刚拍摄 | 显示 `Capturing/Developing/Saving` 对应状态 |
| 历史照片 | 直接显示已完成状态 |
| 返回 | 回到 `detailOrigin` |
| 失败重试 | 使用 `lastTaker` 和 `lastImprint` 再拍 |
| 收藏 | 切换持久化 id 集合 |
| 分享 | 通过 FileProvider 分享 full JPEG |
| 打开系统相册 | 通过真实 MediaStore URI + `ACTION_VIEW`；未发布时按钮禁用 |
| 滚动 | 照片/参数可滚动，动作条固定 |

**状态细节：**

- 显影秒表只在 Processing/Writing 运行；
- 失败说明“重试会生成新照片”；
- 缩略图缺失时不退回全尺寸，而显示原图仍在的说明；
- 历史照片的 EXIF 可读取时显示真实值，否则为 `—`。

**视觉保留：**

- Processing 不能显示假百分比；
- 动作区的可用性与 `galleryPublished` 一致；
- 分享与系统相册打开不能被视觉层替换成不可执行控件。

## 6. `FILMS` 交互

| 控件/手势 | 当前行为 |
|---|---|
| 当前卷大卡 | 回相机 |
| 支持且非当前的胶卷行 | 选中新胶卷 |
| 当前胶卷行 | 不重复选择 |
| 不支持胶卷 | 不可点击，显示原因 |
| 重新扫描 | 扫描 `files/film/`，更新列表 |
| TabBar | 平级导航 |

**状态保留：**

- 选择胶卷只改变后续拍摄使用的卷和照片筛选，不重置计数；
- 不支持卷必须保持不可执行；
- 历史缩略图只能来自真实照片；
- 扫描中/完成/失败目前没有独立视觉状态，改版可添加，但不能虚构进度。

## 7. `DISCOVER` 交互

- 仅可滚动和通过 TabBar 切换。
- 没有内容项、点赞、账户、网络加载或推荐交互。
- 数字随本地数据刷新。
- 改版若改变“发现”的页面语义，属于产品决策，不属于视觉改版；当前应继续呈现本机档案概览。

## 8. `SETTINGS` 交互

| 控件 | 行为 | 状态源 |
|---|---|---|
| 片边整行 | 切换并持久化 | `ImprintSettings.filmEdge` |
| 日期后背整行 | 切换并持久化 | `ImprintSettings.dateBack` |
| 重新扫描胶卷 | 刷新胶卷并 Toast | `FilmStockCatalog` |
| 开源与素材声明 | 打开覆盖内容 | 本地状态 |
| 声明返回 | 关闭覆盖层 | `BackHandler` |
| 运行成像自测 | 仅 debug/benchmark 显示 | `BuildConfig.DEBUG` |
| TabBar | 平级导航 | 当前页显示 |

**反视觉欺骗规则：**

- 开关必须真实持久化；
- 未接入的设置不可画成可点；
- 设备路径、张数、版本和许可内容必须真实；
- 关掉贴花只影响新拍照，已拍照片不重写。

## 9. 动效与反馈

### 9.1 当前实际

- 玻璃控件：按下后通过 backdrop 图层放大约 2dp，外/内阴影和边缘高光随按压增强，无 ripple。
- 底部 Tab：按下缩到 0.96，颜色动画 180ms。
- 快门：74dp 白盘/外环，使用轻震后回调；视觉本身没有统一 backdrop 按压动画。
- 快门闪白：0.82 → 0，320ms，画在整棵树之上。
- EV 面板：fade + scale 140ms 进入，110ms 退出。
- 目的地抽屉：fade 150ms 展示遮罩，260ms 上滑 + fade 进入。
- 详情显影弧：每 60ms 小幅转角；真实秒表约 1s 更新。
- 查看器图片：异步解码，无进入动画。

### 9.2 改版应统一

- 建立一套“仪器反馈”：短促、可预测、低弹性；
- 主操作、图标操作、列表行和模态关闭都采用同一套层级；
- 触觉只在主操作和状态切换使用；列表滚动不震；
- 尊重系统减少动效设置；
- 不把快门闪白移出全局顶层。

## 10. 无障碍与触控现状

实际具备：

- 图标按钮通常有 `contentDescription`、`Role.Button` 和点击标签；
- Tab 使用 `Role.Tab`；
- 设置开关整行可点；
- 相机权限空态有可读按钮；
- 详情/查看器有可读图片或说明。

当前待改善：

- 相机顶栏/变焦按钮实际 44dp；
- `GlassChip` 可点高度可能小于 48dp；
- 图标按钮的视觉“玻璃圆形”没有统一焦点态；
- 横屏和 320dp 状态尚未真机验证；
- 文字对比度需要 Darkroom Instrument 新色板重新计算；
- 需要真实 TalkBack 顺序，尤其相机底层在详情期间仍在组合树内。

视觉改版至少保留 48dp 热区、角色、标签、点击动作与焦点顺序，不新增无语义图片按钮。

## 11. 交互验收真机脚本

1. 冷启动 → 相机权限允许/拒绝；
2. 横持相机 → 闪光开 → 3× 变焦 → EV +0.3 → 九宫格开 → 拍一张；
3. 快门后 1 秒内观察详情页，不切页；
4. 返回相机 → 进相册 → 回相机，检查闪光/变焦/EV 恢复；
5. 相册筛选全部/收藏/各卷；
6. 查看器左右循环、收藏、详情、返回；
7. 详情分享、系统相册打开、失败重试；
8. 胶卷库选择支持卷，尝试不可支持卷；
9. 设置开关贴花后拍一张，再关闭后拍一张；
10. 从系统相册删除一张，回 App 验证列表；
11. 320dp、411dp、平板宽屏各检查首屏；
12. 字体系数放大、减少动效、API 29/30 各检查一次。
