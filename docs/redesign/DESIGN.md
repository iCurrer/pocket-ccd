# Pocket CCD — Darkroom Instrument

**版本：** 1.0  
**日期：** 2026-11-03  
**适用基线：** Pocket CCD 0.8.8  
**性质：** 后续视觉改版的目标规范，不代表当前界面已实现。

## 1. 产品定位

Pocket CCD 不是普通相机 App，也不是“套着胶片滤镜的拍照工具”。它是一台装在手机里的玩具数码相机：打开是取景器，按下快门后，一帧真实场景经过一套有物理含义的显影与印相过程，成为带有胶片材质、片边、日期后背和个人档案属性的成片。

**Darkroom Instrument** 将这一定位转化为视觉语言：

> 取景器是一台精密但亲切的测光/摄影仪器；拍下的照片进入暗房工作台；相册是一张张接触印样，也是一份可追溯的本地底片档案。

这不是复古皮革、黄铜道具或模拟机械相机的 cosplay。界面仍应是成熟、快速、可读的 Android 应用，只是把“操作相机、等待显影、查看参数、归档底片”做得像使用一件目的明确的暗房工具。

### 1.1 用户印象

第一眼应感到：

- 黑、安静、专注；
- 结构和读数清楚；
- 光线有方向，有材质，不漂浮；
- 照片是唯一真正鲜艳的内容，UI 不与之争抢；
- 有摄影器材的可信度，但没有专业相机的门槛。

不应感到：

- 冷蓝色 Material 模板；
- 很多同质玻璃卡片；
- 每个控件都是一个圆角胶囊；
- 暗色主题只把白字放进黑底；
- 复古元素只是装饰贴纸；
- 模块很多但层级没有变化。

## 2. 视觉原则

### 2.1 影像是光源，界面是暗房

- 相机预览与成片是画面中的最高亮度内容；
- UI 使用碳黑、石墨、烟熏玻璃和低透明象牙白；
- 强调色只在可操作状态、读数和主操作上出现；
- 不使用大面积渐变抢照片的颜色。

### 2.2 一个结构，一套语言

- 相机横屏与竖屏可以改变排布，但必须共享同一套刻度、边框、光学重心和反馈；
- 胶卷、相册、详情、设置都使用同一个“仪器面板 + 接触印样 + 印刷铭牌”家族；
- 不用“相机像机械仪器、其它页像 Material 设置页”的分裂体系。

### 2.3 层级通过材料与位置

优先使用：

- 黑色基座；
- 烟熏玻璃插入层；
- 一条有方向的边缘高光；
- 1dp 刻线；
- 数字与单位的字阶差；
- 留白和光学对齐。

避免：

- 所有面板同色同透明度；
- 通过更多边框/更多卡片表达层级；
- 给每个内容块都套一个大圆角背景；
- 无来源的发光、彩色胶囊和阴影堆叠。

### 2.4 可操作物必须像可操作物

- 快门是唯一最强主操作；
- 变焦与 EV 是带档位的仪器控制，不是普通文字按钮；
- 胶片切换是明确的选择，不是偶然点到的卡片；
- 不可用状态必须保持可识别，并解释原因；
- 可点的 chip、按钮、列表行至少 48dp 热区。

### 2.5 读数必须真实、克制

- 屏幕上只显示能解释当前决策的数据；
- 胶卷名、现存照片数、真实 EV、真实变焦、真实 EXIF 可以显示；
- 不显示假 ISO、假光圈、假容量、假进度；
- 没有数据就留空、省略或显示 `—`；
- 数字使用等宽或 tabular 字形，避免变化时左右跳动。

## 3. 色彩

### 3.5 使用规则

- 单页同时出现的有色区域不超过两类：琥珀强调 + 一个状态色；
- 红色不用于普通删除之外的品牌强调；
- 选中状态不能只靠颜色，必须有位置、底形或指示线；
- 正文与背景对比度 ≥ 4.5:1，大标题和图标 ≥ 3:1；
- 文字颜色不得使用低于 `textTertiary` 的透明度承载信息；
- 真实照片上的文字必须使用 black veil 或局部深底。

## 4. 字体

不打包字体，使用系统 `SansSerif` 与 `Monospace`。

### 4.1 字阶

| Token | 规格 | 用途 |
|---|---|---|
| `display` | Sans 28/32, SemiBold | 极少数页面主标题 |
| `title` | Sans 24/30, SemiBold | 页面主标题 |
| `section` | Sans 16/22, Semibold | 分区/卡片标题 |
| `body` | Sans 14/21, Normal | 主正文 |
| `caption` | Sans 12/18, Normal | 说明 |
| `label` | Sans 12/16, Medium | 控件标签 |
| `microLabel` | Sans 11/14, Medium | 必要的小标签，最低值 |
| `numeric` | Mono 12/16, Medium | EV、倍率、EXIF、日期 |
| `numericLarge` | Mono 18/22, SemiBold | 主读数 |
| `numericHero` | Mono 32/32, SemiBold | 唯一的页面级大读数 |

### 4.2 排版规则

- 页面标题左对齐，数字读数右对齐或居中；
- 单位比数值小一档，例如 `+0.3` 与 `EV`；
- 标签可以使用全大写，但正文不使用大写；
- 中文正文使用 Natural tracking，不拉宽；
- 参数行用 `label + value` 两列，值使用 Mono；
- 不使用 9sp/7sp 作为真实信息；
- 滚动列表允许内容自然增高，用换行与删减解决溢出，不缩字号。

## 5. 间距与栅格

基础栅格为 4dp。

| Token | 值 | 用途 |
|---|---:|---|
| `space2` | 8dp | 紧密同组 |
| `space3` | 12dp | 控件间距 |
| `space4` | 16dp | 面板内边距 |
| `space5` | 20dp | 页面左右边距 |
| `space6` | 24dp | 大卡片内边距 |
| `space8` | 32dp | 区块间距 |
| `space12` | 48dp | 最小触控安全区 |

### 5.1 页面

- 竖屏内容边距：20dp；
- 相机横屏左右工具区：20dp；
- 顶部偏移避开状态栏；
- 底部导航浮层预留：至少 108dp；
- 详情动作条位于导航栏 inset 之上；
- 平板/折叠展开最大内容宽度：560dp；
- 超过 600dp 时优先扩展两侧留白，不做无限拉伸。

### 5.2 相机

- 取景窗是页面第一视觉；
- 横屏 4:3 窗口吃满可用高度，左右留工具区；
- 竖屏 3:4 窗口保持拍摄结果的完整构图；
- 快门、相册、闪光与主要工具之间至少 8dp；
- 相邻热区不得重叠；
- 控制组不遮盖照片主体；展开面板优先贴近底部/边缘。

## 6. 形状

| Token | Value | 用途 |
|---|---:|---|
| `control` | 14dp | 方形仪器键、读数窗 |
| `chip` | 18dp | 可选档位/标签 |
| `card` | 20dp | 参数卡、设置组 |
| `panel` | 28dp | dock、动作条、模态面板 |
| `image` | 4dp | 照片画框，避免把影像做成 App 卡片 |
| `viewfinder` | 18dp | 取景窗 |
| `circle` | 50% | 只用于真正的圆形实体控件 |

### 6.1 使用规则

- 照片画框使用小圆角，保持影像本身完整；
- 圆角越大，面板越像“浮层”；不要让所有内容都同样大圆角；
- 圆形只用于快门、图标钮等确有圆形实体隐喻的控件；
- 变焦和 EV 优先使用刻度/轨道，不把各档做成互相独立的胶囊组；
- 细边框 1dp，不超过 1.5dp；
- 外阴影低而短，避免每个卡片都有“漂浮”感。

## 7. 材质

### 7.1 三类材质

1. **炭黑基座**：页面底、取景器周围、导航背景；
2. **烟熏玻璃**：dock、动作条、模态控制层；
3. **深色金属/印刷面**：仪器面板、读数窗、选中刻度。

### 7.2 玻璃规则

- 只有背后有可采样内容时才启用真实 blur/lens；
- 相机预览是独立 Surface，不使用假模糊；
- 玻璃必须有方向性边缘光，不能是纯半透明矩形；
- 大面板和内嵌小控件使用不同层级，不做同质大卡片；
- API 29/30 用深色填充 + 1dp 高光退化，视觉效果仍要可读；
- 按压时整体轻微收拢或内压，波纹与塑料感默认关闭。

### 7.3 暗房材质

可作为局部内容材质：

- 黑色相纸托盘；
- 深棕黑片基；
- 暖金属刻度；
- 点阵日期印刷；
- 真实片边/齿孔图像只出现在成片像素中，不用 UI 贴图伪造。

## 8. 图标与图形

- 继续使用 Material Symbols Rounded 原始几何；
- 默认 18–24dp，主图标 24dp；
- UI 图标线色使用主/次文字色；
- 填充只用于收藏、曝光、确认等已有实心变体的语义；
- 不用 emoji；
- 不用手绘“差不多像”的替代图标；
- 对焦、裁切角、刻度、分隔线可以使用 Canvas，但必须与图标笔画重量一致；
- 胶卷筒是可识别的物件图像，可用于“未拍摄”状态，但不得冒充真实样片。

## 9. 组件规则

### 9.1 Instrument Surface

- 用在底部 dock、动作条、详情参数、设置组、抽屉；
- 烟熏玻璃或石墨塑料二选一；
- 内边距 16–20dp；
- 1dp 边缘光；
- 不承载无意义装饰圆点。

### 9.2 Icon Control

- 视觉直径 40–44dp，热区 48dp；
- 图标 18–20dp；
- 默认透明或烟熏底；
- 激活状态显示琥珀读数/指示灯；
- 禁用状态降低对比度并保留轮廓。

### 9.3 Selector / Dial

- 用于变焦、EV、筛选；
- 具有明确档位和当前值；
- 用户可以只点一个档位，也可以视觉上读出当前位置；
- 不用无边界的 chip 序列表达机械档位。

### 9.4 Shutter

- 唯一主操作，建议 72dp 外环 + 58dp 实心面 + 80dp 热区；
- 同心圆即可，不用装饰性滚花密集到产生摩尔纹；
- 不可用时保留轮廓并显示原因；
- 按下有短促压缩、1dp 内压和轻触反馈；
- 闪白由全局层负责，不能放进相机页面内部。

### 9.5 Photo Frame

- 图片框 4dp 圆角；
- 4:3/3:4 由图片真实方向决定；
- 网格可以使用统一方形裁切，但查看器/详情必须展示完整照片；
- 不在图片内部叠加常驻参数；
- 读取中显示仪表式加载状态，失败显示独立错误。

### 9.6 Contact Sheet Tile

- 缩略图是主要信息，不加无意义阴影；
- 角标只表达收藏；
- 图片缺失时有稳定占位；
- 采用真实照片，不画虚构样片；
- 网格允许 3 列；平板可扩到 4 列，但不得把点击目标压到 48dp 以下。

### 9.7 Settings Row

- 整行可点，最小 56dp，带说明时自然增高；
- 左侧标签，右侧值/开关；
- 开关可以是定制拨杆，但必须有清晰开/关；
- 分隔线只在组内使用；
- 不把未实现的设置画成灰色按钮。

### 9.8 Navigation

- 五项底部导航保留；
- 中间“拍摄”可以被视觉强调，但不能变成无法返回相机的装饰；
- 选中态用图标 + 文字 + 底部指示，不只靠颜色；
- 查看器与详情隐藏；
- TabBar 背后有内容时可以真实模糊，否则静态玻璃。

## 10. 页面方向

### 10.1 Camera

- 主画面：4:3 取景窗；
- 顶部/侧边的光学布局必须把真实读数放在边缘，不遮主体；
- 横屏是拍摄主环境；
- 横屏应有完整的状态反馈与目的地入口；
- 竖屏可以保留同一结构收窄，但不能用完全不同的视觉体系；
- 快门始终是唯一最高视觉重量。

### 10.2 Gallery

- 以接触印样为核心，不做“卡片收藏流”；
- 页头简短，筛选像刻度或索引；
- 照片之间的间隔小于照片边距，强调连续浏览；
- 收藏标记是明确的小状态，不是大面积动作块；
- 底部导航与内容之间留出干净呼吸带。

### 10.3 Detail

- 页面像暗房工作台：照片在中心/上部，参数是下方读数区；
- 处理中显示真实阶段 + 计时，不显示百分比；
- 完成后显示真实 EXIF 和设备信息；
- 动作区固定在底部，但必须与导航栏 inset 协调；
- 横版照片应在横版照片框完整出现，不强行裁成竖幅。

### 10.4 Films

- 当前胶卷是有实体身份的整卡，候选卷是从属列表；
- 选卷状态清晰，不依赖微弱颜色差；
- 不显示虚构价格、到期日、ISO；
- 不支持卷灰化并给原因，不能伪装成装卷成功。

### 10.5 Discover

- 仍是“本机档案概览”，不扩展内容流；
- 数字作为读数仪表，不使用三张孤立卡片；
- 解释文字保持简洁；
- 页面空数据同样成立。

### 10.6 Settings

- 是相机参数/维护面板，不是系统设置模板；
- 成像开关放在第一组；
- 许可入口清晰可发现；
- 开关、行、版本可采用铭牌式排版；
- 不偷加网络、账户、主题颜色或假设置。

## 11. 动效

| 场景 | 建议 |
|---|---|
| 按压反馈 | 90–120ms 短促内压/收拢，不过度弹跳 |
| 状态变化 | 160–180ms 颜色/高光过渡 |
| 页面切换 | 180–220ms fade + 4–8dp 位移 |
| EV/抽屉面板 | 140–220ms，位置与内容同步 |
| 快门闪白 | 300–340ms，从全屏最上层淡出 |
| 对焦 | 180–300ms 四角收束，2.2s 后淡出 |
| 显影 | 真实秒数 + 稳定循环仪表，不做虚假百分比 |
| 查看器 | 关闭/打开快，优先保持照片位置稳定 |

必须尊重系统的减少动效设置。视觉动效不得延迟快门、相机绑定或清空用户操作。

## 12. 状态设计

每个可操作区域至少设计：

- default
- pressed
- focused
- selected
- disabled
- loading
- success
- error

特别规则：

- loading 与 error 必须区分，不可共用“照片读不出来”；
- 不可用相机和权限拒绝都要有原因和下一步动作；
- 失败状态必须有真实原因，不显示“未知错误”；
- 成功状态不夸大能力，例如“本地已保存”和“已发布系统相册”要区别；
- 空态要有明确动作，但不增加不存在的功能。

## 13. 响应式与无障碍

- 320dp：胶卷名可截断，但所有核心操作仍可见；不使用小于 48dp 的触摸热区。
- 360–411dp：标准相机竖屏与列表布局。
- 804×361dp：横屏相机主场景，工具列不遮取景窗。
- 800dp：内容宽度封顶或布置为适配平板，遵循 App 的强制方向。
- 200% 字体：允许换行和增高，不允许缩到不可读。
- TalkBack：每个 icon-only 控件有明确标签；照片有替代描述；开关整行可读。
- 颜色不是唯一状态：同时使用形状、文字、图标或位置。
- 所有点击热区满足 ≥48dp；现有 44dp 相机控件和约 34dp 玻璃 chip 属于待修正项。

### 15.1 静态

- 光线变化下预览仍原色；

- TabBar 与模态层级正确；
- 本地照片与系统相册副本一致。

### 15.3 主观评审

必须能指出：

- 哪一部分是暗房仪器的“材料”；
- 哪一部分是摄影信息层级；
- 哪些交互具有机械/仪器反馈；
- 哪个页面仍然只是普通 Material 卡片。

如果评审只能说“看起来更黑/更亮”，则 Darkroom Instrument 还没有真正落地。

## 16. 实施顺序

1. **Token 与材质层**：色板、字阶、间距、形状、玻璃 API；
2. **通用控件**：按钮、图标键、chip、selector、导航、空/错/加载；
3. **相机页**：竖屏与横屏共用结构、取景框、快门、工具、状态；
4. **相册与查看器**：真实照片比例、网格、模态；
5. **详情页**：打印/工作台、EXIF、处理状态、动作条；
6. **胶卷/设置**：卡片、列表、开关、许可；
7. **发现页**：统计仪表；
8. **真机验收与截图归档**。

先冻结行为契约，再做视觉替换。任何页面在视觉改造中发现需要业务数据或行为变化的，必须单独标记、单独评审，不混入本轮“纯视觉”改动。
