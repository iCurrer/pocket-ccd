# Pocket CCD — 方向 C「白纸档案」1:1 版面规格（v0.6.0 / B 方案 UI 层）

**日期：** 2026-10-23 ｜ **状态：** IMPLEMENTED（UI 层，v0.6.0）｜ **决策：** D-064
**用户选择：** B 方案——视觉 1:1；功能开发交给其他智能体
**基线：** v0.5.0（commit `ef50bc1`）｜ **设计参照：** 用户提供的 Paper Archive 设计板
**原则：** 本轮只做 **视觉 / 版面 / 导航壳 / 交互反馈**。新增业务功能（发现页内容、滤镜、拍摄模式、保存/分享/删除、账户、更多胶卷 pack、设置子页）由其他智能体接入；UI 留出回调，不伪造数据。

---

## 1. 全局导航壳（新增）

- 纸面页（GALLERY / FILMS / DISCOVER / SETTINGS / RESULT）底部显示 **4 Tab**：
  `相册` / `胶卷` / `发现` / `设置`，图标 20dp + 标签 11sp；高 56dp，顶部 1px hairline，背景纸色，
  底部吃 `navigationBars` inset。
- 选中 = 墨色图标 + 墨色标签 + 字重 Medium；未选中 = `textTertiary`。不做胶囊、不做填底。
- 相机页（CAMERA）不显示 TabBar：启动即全屏取景的硬约束不变。
- 相册查看器（黑底灯箱）打开时隐藏 TabBar，关闭后恢复。
- 页面内容底部统一留 `88dp`（56 导航 + 24 呼吸 + 系统栏），避免被 TabBar 压住。

## 3. 成片页（Photo Detail）

1. 页头按 §2；`05 / 36` 只在真实 `frameIndex/rollCapacity` 存在时显示，否则 `— / —`。
2. 印相：宽 86%（比 v0.5.0 的 88% 略窄）、6dp 纸白边 + 1px 墨线、圆角 2dp、无阴影；图下
   左 18sp Serif 卷名，右 12sp mono `P-05`（真实帧号）。
3. 元数据三行 11sp mono / 行高 18：
   - `2026.10.20 16:42`（真实拍摄时间）
   - `ISO 100 · 1/60s · f/1.8`（只显示真实 EXIF；缺项写 `—`；不补设计稿数值）
   - `OnePlus 13` 改成真实 `Build.MODEL`；取不到就省略
4. 状态行：小圆点 + `显影中 03s`（真实阶段/秒数）；成功态 `已保存 · 03s`。
5. 动作行：4 等分 `保存 / 收藏 / 分享 / 更多`，图标 20dp + 标签 11sp，48dp 热区；
   回调从 `ResultScreen` 参数注入（`onSave / onToggleFavorite / onShare / onMore`），
   **本轮默认空实现，功能由其他智能体接**；收藏态用石板蓝点标。
6. 显影中：同一版面，印相区为纸色空窗 + 状态行；无百分比、无扫描带。
7. 失败/空态沿用纸面说明 + 主按钮。

## 4. 照片墙（Photo Wall）

1. 页头 `Photo Wall`；右侧档案图标。
2. 页签：`全部` / `★ 收藏` / 每个真实卷名（用真实 `GalleryFilter` 列表；不写死 Kodak/Fuji/Ilford）。
   选中 = 墨色 + 2dp 下划线；未选中 `textTertiary`。
3. 网格 3 列：列距 8dp、行距 14dp、页边距 24dp；图 1:1（2dp 圆角、1px hairline）；
   图下 10sp mono 帧号（`01`…）；收藏用石板蓝 6dp 方块。
4. 空态纸面化，动作真实。
5. 查看器保持黑底灯箱（v0.5.0），打开时无 TabBar。

## 5. 胶卷库（Film Library）

1. 页头 `Film Library`；右侧 `+`（接 `onRefresh`，真实重扫；其他智能体可换成导入）。
2. `CURRENT` 卡：**墨黑卡片**（ink 底、纸白字），圆角 2dp；左侧真实成片缩略图（无照片画胶卷筒），
   右侧 `KODAK GOLD 200`、`05 / 36`、36 帧点阵（已曝光纸白 / 未曝光白 25%）、`READY/FULL`。
3. 列表行：56×72 真实缩略图 + 卷名 14sp + `36 张 · 2026.10.20` 10sp mono + 右侧箭头；
   行高 ≥72dp、hairline 分隔、无卡片底。
4. 只列真实 pack 里的胶卷；没有 Fuji/Ilford pack 就不显示，不造假。
5. 装卷 900ms 动画、真实点击装卷保留；底部 88dp。

## 6. 设置（Settings）

1. 页头 `设置`；右侧图标。
2. 四个可展开分类（点击展开/收起，不新增子页）：
   - `01 保存与输出`：保存位置 / 画质 / 胶卷重扫（现有真实行）
   - `02 相机与拍摄`：相机权限（跳系统设置，真实）；其余待其他智能体接入
   - `03 胶卷管理`：胶卷数量 / 重新扫描（现有真实行）
   - `04 关于`：版本 / 隐私 / 开源声明（现有真实行）
   分类行：Serif 17sp + 11sp 副题 + 右侧箭头；展开后现有 `ColophonRow`。
3. 页脚：`Pocket-CCD` Serif + `A Camera App for Film Lovers` 11sp mono +
   `Version / Build`（真实 `BuildConfig`）；作者字段暂不写（无真实来源）。
4. 声明页覆盖层保持全屏 + BackHandler。

## 7. 发现（Discover，脚手架）

- 页头 `发现` / `DISCOVER`。
- 只展示真实数据：`本机照片 N 张` / `可用胶卷 N 卷` / `本卷已拍 NN / 36`；
  其余内容由其他智能体接入（不加假列表、不加“敬请期待”式空话）。
- 无照片/无胶卷时用真实空态 + 去取景/去胶卷库。

## 8. 交互 / 动效（沿用 v0.5.0 令牌）

- 按压 0.97 / 90ms 硬切；状态色 120ms；页面 160ms fade + 8dp；Tab 切换 120ms 交叉淡化。
- 快门 80–100ms 硬切 + 90ms 闪白；对焦 300ms；变焦 160ms；换卷长按 + 纸面确认；显影 500ms 浮现 + 打字机。
- 全部使用 `spec.motion`，不新增写死时长。

## 9. 数据诚实红线

- 只显示真实值；缺项 `—`；不写 ISO/光圈/快门/机型以外的设计稿数字。
- 不伪造胶卷、不伪造容量、不伪造订单/进度/账户。
- 新按钮（保存/分享/更多/发现内容）允许先接空回调，但必须在交接文档中列出“待其他智能体接入”。
